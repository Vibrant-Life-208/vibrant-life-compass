### Say this first, out loud, once

> **"Pass is always allowed. Skip anything. Nothing is owed."**

Say it once at the start so it does not have to be repeated into every question.

### The shape

**Arrival.** Sit, eat, no agenda for a few minutes. · **The settle.** Thirty seconds, feet on the floor, one breath. Offered, not required. · **The questions.** Pick from them. Never run them all. · **A taste.** Ten minutes, built from their question where there is one. · **The out**, inside the taste. · **The close.** Then: *"you don't have to decide anything today."*

About 45 minutes. Shorter is fine. **The learner ends it whenever they want.**

### How to ask

**One question, then stop. Count to five before you say anything else.** Do not stack examples onto a question: the examples are you answering it for them, and a sixteen-year-old hears that as the adult being nervous. "I don't know" is a complete answer, and so is a shrug.

### The groups, one anchor each

| | Anchor question |
|---|---|
| Opening | What did your family tell you this is? What do you think it is? |
| Why here | Is there anything you would miss? |
| A live question | What can't you stop thinking about? |
| Nobody made you | What have you learned that nobody made you learn? |
| Saying no | When was an adult wrong and you knew it? |
| People, alone | Six or seven people, one room, three years. What's good about that? What's hard? |
| Rest | What do you do when nothing is required of you? |
| Your own mornings | Mondays and Wednesdays are yours. What would you do with them? |
| How you work | What helps you learn? What gets in the way? |
| Close | What haven't I asked that you wish I had? |

### The out

Somewhere inside the taste, hand them something to decline:

> **"Here's a part of this you can say no to right now, and I'd like to see you do it if it isn't yours."**

### The signs. Yes, no, or not seen. No numbers. Never ranked.

| # | Sign | Y / N / not seen | One sentence of what was seen |
|---|---|---|---|
| 1 | A live question, or a thing already in motion | | |
| 2 | Something done that nobody required | | |
| 3 | Can say no to an adult | | |
| 4 | Can be witnessed, and can witness | | |
| 5 | A relationship to rest | | |
| 6 | A family that can hold the covenant | | |
| 7 | Access needs the room can hold, or warmly refer | | |
| 8 | The learner's own yes *(a week later, alone)* | | |

**Watch for:** sign 1 is not "knows what they want." Sign 2 is not a resume. Sign 3 is not charm or the fast yes. Sign 4 is not confidence or volume; the quiet witness counts fully. Sign 5 is not a full calendar. Sign 6 is not a family that agrees fast.
